# Hear Me Out

**Live demo: https://coachs-copilot.onrender.com** (free tier: the first load may take about a minute).

A second listener for health-coaching calls (eMerge Challenge 5, Coach's Copilot). eMerge AI Hackathon 2026, Healthcare track.

Bilingual (English/Spanish) tool for health-coaching conversations. It tags what the coach is doing, scores the call against motivational-interviewing practice, and flags any sentence a person should see today by quoting it. It gives no diagnosis and no medical advice: it points a human to the sentence and shows why.

## What is in this repo
- `src/` the engine: schema check (`schema.py`, `loader.py`), rule tagger (`tagger/`), needs-a-human flagger with a negation guard (`flagger/`), score card (`score/`), local JSON API (`api.py`), optional local classifier (`classifier.py`).
- `ui/` the interface generated by Archie (React + Vite), with a demo mode and a Try a conversation page that calls our engine.
- `eval/` an offline evaluation harness (precision, recall, F1, kappa, confusion matrix) written by Devin.
- `src/eval_annomi.py`, `src/train_annomi.py` local scripts a human runs on the organizers' data; they print only aggregates.
- `tests/` unit tests on invented, fictional lines (`tests/fixtures/`). `WALKTHROUGH.md` explains each module, its limit, and why it is built that way.

## Run it (no data needed)
```bash
python3 -m unittest discover -s tests -t .      # tests (Python 3, no packages to install)
python3 -m src.api --port 8000                  # local API on fictional fixtures
cd ui && npm install && VITE_DEMO_MEMORY=1 npx vite --port 3000   # UI in demo mode, no account
```
Then open http://127.0.0.1:3000/live-analyzer and pick a fictional call or type an English or Spanish line.

## Data and privacy (kept OUT of this repo, by the hackathon terms)
No challenge data, labels, weights or keys are committed; `.gitignore` excludes them. The scripts read the organizers' files from `COACH_DATA_DIR` and write predictions and weights to a folder outside the repo. No model API is called by the app: `/api/explain` answers 409 unless `LLM_APPROVED=1`, and it is off.

## Modes: rules-only (public repo) and local classifier
The public repo runs in **rules-only mode with no data and no weights**. Weights are produced locally from the organizers' data (`src/train_annomi.py`) and are deleted after Oct 19; they are never committed. To use them, set `COACH_CLASSIFIER_DIR` to the folder that holds them and the tagger will use the classifier for coach moves and client talk (safety flags always stay rule-based). Accuracy was measured on held-out sessions that the classifier never trained on; the numbers are reported on the slide, not stored in this repo.

## Honest limits
The rules are our own heuristics, so accuracy on real calls is modest; the S1 to S3 safety tiers are our own design, not the organizers'. The flagger is a triage aid, not a safety system. In the interface, the queue, review and scorecard screens show invented people and calls whose flags, coach-move tags, scores and checklists are generated by our engine (`scripts/gen_ui_fixtures.py`); the people, titles and dates are fictional. Nothing here is a diagnosis.
